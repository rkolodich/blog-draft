# Blog

Blog site based on Eleventy

## How to run

- Install `node.js`
- Run `npm run dev`

## Commands

- `dev` - run server for development
- `build` - build project for production
- `lit` - lint all files

## Structure

- `_11ty`
- `_data`
- `_includes`
- `_layouts`
- `_share`
- `dist`
- `assets`
- `src`
